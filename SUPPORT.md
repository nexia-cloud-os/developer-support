# Nexia 개발자 지원 / Developer support

개발환경 설치, CLI·SDK·Docker, AI 개발 도구 연결, 샌드박스 실행, 핫리로드와 심사 제출 문제는 [통합 이슈 창구](https://github.com/nexia-cloud-os/developer-support/issues)에 등록하세요. 어느 패키지의 문제인지 먼저 판단할 필요가 없습니다.

Report setup, CLI, SDK, Docker, AI development-tool integration, sandbox, hot-reload and review-submission problems in [one issue tracker](https://github.com/nexia-cloud-os/developer-support/issues). You do not need to identify the owning package first.

1. [기존 이슈 검색 / Search existing issues](https://github.com/nexia-cloud-os/developer-support/issues).
2. [문제 신고 / Report a problem](https://github.com/nexia-cloud-os/developer-support/issues/new/choose).
3. Include the affected package and version, development mode, OS/browser, reproduction steps, expected and actual behavior, and a minimal sanitized error excerpt. For sandbox incidents, include the approximate time and timezone.

이 저장소는 공개입니다. 비밀번호, 토큰, 쿠키, 연결 코드, `.env`, CLI 인증 파일, 고객 데이터와 Core 소스는 첨부하지 마세요. 보안 취약점은 공개 이슈 대신 [비공개 보안 제보](https://github.com/nexia-cloud-os/developer-support/security/advisories/new)를 사용하세요.

This tracker is public. Never attach credentials, pairing codes, customer data or private Core source. Use [private vulnerability reporting](https://github.com/nexia-cloud-os/developer-support/security/advisories/new) for security vulnerabilities.
